# Backend con Java - Prácticas del Curso de Henry

Este repositorio contiene las prácticas realizadas durante el curso **"Backend con JAVA"** de Henry. Aquí se aplican conceptos fundamentales de desarrollo backend utilizando Java y Spring, a través de ejercicios prácticos que cubren los siguientes temas:

## Contenido del curso

- **Fundamentos de Java:** Dominio de la sintaxis y principios de la programación orientada a objetos.
- **Manejo de datos:** Uso de las librerías `Collections` y `Generics` en Java.
- **Conexión a bases de datos:** Implementación de JDBC, H2 y el patrón DAO para gestionar datos.
- **Pruebas y calidad de código:** Uso de JUnit 5 y Mockito para pruebas unitarias y desarrollo guiado por pruebas (TDD).
- **Desarrollo de APIs:** Creación de APIs RESTful con Spring Boot y el patrón MVC.
- **Gestión de dependencias y logging:** Uso de Maven y mejores prácticas para el registro de eventos.
- **Persistencia de datos:** Empleo de Hibernate y Spring Data JPA para la gestión de la base de datos.
- **Patrones de diseño y programación funcional:** Implementación de patrones de diseño y uso de la librería Stream API.
- **Pruebas de integración:** Verificación de la funcionalidad completa de las APIs desarrolladas.
